# ZKBLAST deployment manifests

Deployment manifests are generated by the contract deployment script; they are not
edited by hand. Each environment has exactly one canonical path:

- `deployments/testnet/manifest.json`
- `deployments/mainnet/manifest.json`

The manifest records proxy and implementation addresses separately, initializer
arguments and calldata hash, every deployment/configuration transaction, block and
gas data, bytecode hashes, roles, compiler settings, and explorer verification state.
Application code must resolve addresses from the selected environment manifest and
must never hardcode deployed addresses.

The private key remains only in the local environment file. It is never copied into
the manifest, console output, web bundle, or application response.
